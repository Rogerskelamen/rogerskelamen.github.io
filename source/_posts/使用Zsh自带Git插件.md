# Git plugin in Zsh

> Of course you can use `plugins = (git)` in `~/.zshrc` to activate the git plugin in your zsh. But do you really know how to use it elegantly?

*Ok, Don't worry, here are some abbressions for `git`, which are frequently used during developing*

- `g`: `git`

- `gcl`: `git clone`

- `gst`: `git status`

- `ga`: `git add`

- `gc`: `git commit`

- `gp`: `git push`

- `gb`: `git branch`

- `gco`: `git checkout`

- `gr`: `git remote`

- `gm`: `git merge`
