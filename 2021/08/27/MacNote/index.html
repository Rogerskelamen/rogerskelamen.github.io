Mac Note

This note is all about my experience when using the MacOS, it records every confusion and tip.

.DS_Store

Full name is Desktop Services Store

This file can be easily seen in many directories. And because of the prefix ., it obviously a hidden file. This file is desgined by Apple Comp, and created by Finder (a expoler system in MacOS)

this is used to store the icon position and background color(you know, the signed color)

similar to desktop.ini in Windows

.localized

At first, I was so confused about this file. Its size is 0 (empty file), it appears in some directories but not all.

this file is just a localized file, like its name, it does a job that translates your directories into your preferred language.
