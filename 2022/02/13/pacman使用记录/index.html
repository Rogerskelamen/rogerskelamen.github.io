pacman使用

-S(Synchronize)

  • 安装

    sudo pacman -S [package]

  • 模糊查询所有软件包

    sudo pacman -Ss [word]

  • 查询软件包信息

    sudo pacman -Si [package]

  • 更新软件源

    sudo pacman -Syy

  • 更新软件源并更新所有包

    sudo pacman -Syyu

  • 删除所有的安装包缓存

    sudo pacman -Sc

-R(Remove)

  • 删除包的全局配置文件和所有依赖包

    sudo pacman -Rns [package]

-Q(Query)

  • 查询可更新的包

    sudo pacman -Qu

  • 查询自己安装的包(非自动安装)

    sudo pacman -Qe

  • 删除孤包

    sudo pacman -R $(pacman -Qdtq)
